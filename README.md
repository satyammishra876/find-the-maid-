# Find the Maid

A clean and simple UI for booking home services like Cleaning, Cooking, Baby Care, and Full Time Maid.

## Features
- Popular Services section
- Available Near You (with ratings & hourly rates)
- Search bar
- Basic responsive design

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
Just open `index.html` in any browser.
